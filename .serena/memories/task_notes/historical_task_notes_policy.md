# Historical Task Notes Policy

Task notes are chronological records, not always current instructions.

When older task notes conflict with newer memories:
1. Prefer explicit user direction with latest date.
2. Prefer `task_notes/3d_rework_current_state` for the flyfishinggame 3D runtime.
3. Treat older implementation notes as useful history/diagnosis, not active requirements.
4. Do not average conflicts; surface the stale note if it could cause wrong work.
